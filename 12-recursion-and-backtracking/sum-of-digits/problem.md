# Sum of Digits of a Number

- Source: [GeeksforGeeks](https://www.geeksforgeeks.org/problems/sum-of-digits1742/1)
- Platform: GeeksforGeeks

## Problem Description

Given a positive number `n`. Find the sum of all the digits of `n`.

## Examples

### Example 1:
- **Input:** `n = 687`
- **Output:** `21`
- **Explanation:** Sum of 687's digits: `6 + 8 + 7 = 21`

### Example 2:
- **Input:** `n = 12`
- **Output:** `3`
- **Explanation:** Sum of 12's digits: `1 + 2 = 3`

## Constraints

- `1 <= n <= 10^5`
