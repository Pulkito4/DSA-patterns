# Remove all occurrences of a character in a string

- Source: [GeeksforGeeks](https://www.geeksforgeeks.org/problems/remove-all-occurrences-of-a-character-in-a-string/1)
- Platform: GeeksforGeeks

## Problem Description

Given a string `s` and a character `c`. The task is to remove all the occurrences of the character in the string.

## Examples

### Example 1:
- **Input:** `s = "geeksforgeeks", c = 'e'`
- **Output:** `"gksforgks"`

### Example 2:
- **Input:** `s = "geeksforgeeks", c = 'g'`
- **Output:** `"eeksforeeks"`

## Constraints

- `1 <= |s| <= 10^5`
