# Minimum Subarray Sum

- Source: [GeeksforGeeks](https://www.geeksforgeeks.org/problems/smallest-sum-contiguous-subarray/1)
- Platform: GeeksforGeeks

## Problem Description

Given an array, find the contiguous subarray containing at least one element that has the minimum possible sum, and return that sum.

## Examples

Input: `arr = [3, -4, 2, -3, -1, 7, -5]`

Output: `-6`

The minimum-sum subarray is `[-4, 2, -3, -1]`.

Input: `arr = [2, 6, 8, 1, 4]`

Output: `1`

The minimum-sum subarray is `[1]`.

## Constraints

- `1 <= arr.size() <= 10^6`
- `-10^7 <= arr[i] <= 10^7`
