# Kth Smallest

- Source: [GeeksforGeeks](https://www.geeksforgeeks.org/problems/kth-smallest-element5635/1)
- Platform: GeeksforGeeks

## Problem Description

Given an integer array `arr[]` and an integer `k`, find and return the `k`th smallest element in the given array.

> **Note:** The `k`th smallest element is determined based on the sorted order of the array.

## Examples

### Example 1:
- **Input:** `arr[] = [10, 5, 4, 3, 48, 6, 2, 33, 53, 10], k = 4`
- **Output:** `5`
- **Explanation:** 4th smallest element in the given array is 5.

### Example 2:
- **Input:** `arr[] = [7, 10, 4, 3, 20, 15], k = 3`
- **Output:** `7`
- **Explanation:** 3rd smallest element in the given array is 7.

## Constraints

- `1 <= arr.size(), arr[i] <= 10^5`
- `1 <= k <= arr.size()`
