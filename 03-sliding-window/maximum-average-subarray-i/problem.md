# Maximum Average Subarray I

- Problem ID: 643
- Difficulty: Easy
- Source: [LeetCode](https://leetcode.com/problems/maximum-average-subarray-i/description/)
- Platform: LeetCode

## Problem Description

Find a contiguous subarray of length exactly `k` with the maximum average value.

## Examples

- `nums = [1,12,-5,-6,50,3], k = 4` -> `12.75000`
- `nums = [5], k = 1` -> `5.00000`

## Constraints

- `1 <= k <= n <= 10^5`
- `-10^4 <= nums[i] <= 10^4`
