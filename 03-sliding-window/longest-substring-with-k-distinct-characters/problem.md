# Longest Substring with K Distinct Characters

- Source: [GeeksforGeeks](https://www.geeksforgeeks.org/problems/longest-k-unique-characters-substring0853/1)
- Platform: GeeksforGeeks

## Problem Description

Given a lowercase string `s` and an integer `k`, find the length of the longest substring containing exactly `k` distinct characters. Return `-1` if no such substring exists.

## Examples

Input: `s = "aabacbebebe"`, `k = 3`

Output: `7`

The longest substring is `"cbebebe"`.

Input: `s = "aaaa"`, `k = 2`

Output: `-1`

Input: `s = "aabaaab"`, `k = 2`

Output: `7`

## Constraints

- `1 <= s.size() <= 10^5`
- `1 <= k <= 26`
