# Maximum Sum Subarray of Size K

- Source: [GeeksforGeeks](https://www.geeksforgeeks.org/problems/max-sum-subarray-of-size-k5313/1)
- Platform: GeeksforGeeks

## Problem Description

Given an integer array and a number `k`, return the maximum sum of a contiguous subarray of size `k`.

## Examples

Input: `arr = [100, 200, 300, 400]`, `k = 2`

Output: `700`

Input: `arr = [1, 4, 2, 10, 23, 3, 1, 0, 20]`, `k = 4`

Output: `39`

Input: `arr = [100, 200, 300, 400]`, `k = 1`

Output: `400`

## Constraints

- `arr.size() <= 10^6`
- `0 <= arr[i] <= 10^6`
- `1 <= k <= arr.size()`
