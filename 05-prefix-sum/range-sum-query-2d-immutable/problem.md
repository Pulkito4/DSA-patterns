# Range Sum Query 2D - Immutable

- Problem ID: 304
- Difficulty: Medium
- Source: [LeetCode](https://leetcode.com/problems/range-sum-query-2d-immutable/description/)
- Platform: LeetCode

## Problem Description

Implement `NumMatrix` to answer the sum of elements inside any rectangle from `(row1, col1)` to `(row2, col2)` in `O(1)` query time.

## Examples

For the standard 5x5 example, the queries return `8`, `11`, and `12`.

## Constraints

- `1 <= rows, cols <= 200`
- Matrix values are between `-10^4` and `10^4`.
- At most `10^4` calls to `sumRegion`.
