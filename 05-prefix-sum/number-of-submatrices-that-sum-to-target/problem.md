# Number of Submatrices That Sum to Target

- Problem ID: 1074
- Difficulty: Hard
- Source: [LeetCode](https://leetcode.com/problems/number-of-submatrices-that-sum-to-target/description/)
- Platform: LeetCode

## Problem Description

Given a matrix and a target, return the number of non-empty submatrices whose sum equals the target.

## Examples

- `[[0,1,0],[1,1,1],[0,1,0]], target = 0` -> `4`
- `[[1,-1],[-1,1]], target = 0` -> `5`
- `[[904]], target = 0` -> `0`

## Constraints

- `1 <= rows, cols <= 100`
- `-1000 <= matrix[i][j] <= 1000`
- `-10^8 <= target <= 10^8`
