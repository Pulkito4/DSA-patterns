# Container With Most Water

- Problem ID: 11
- Difficulty: Medium
- Source: [LeetCode](https://leetcode.com/problems/container-with-most-water/description/)
- Platform: LeetCode

## Problem Description

Given an integer array `height`, choose two vertical lines that form a container with the x-axis and hold the maximum amount of water.

## Examples

- `height = [1,8,6,2,5,4,8,3,7]` -> `49`
- `height = [1,1]` -> `1`

## Constraints

- `2 <= height.length <= 10^5`
- `0 <= height[i] <= 10^4`
