# Trapping Rain Water

- Problem ID: 42
- Difficulty: Hard
- Source: [LeetCode](https://leetcode.com/problems/trapping-rain-water/description/)
- Platform: LeetCode

## Problem Description

Given non-negative bar heights where each bar has width 1, compute how much water can be trapped after raining.

## Examples

- `height = [0,1,0,2,1,0,1,3,2,1,2,1]` -> `6`
- `height = [4,2,0,3,2,5]` -> `9`

## Constraints

- `1 <= height.length <= 2 * 10^4`
- `0 <= height[i] <= 10^5`
