# Find Position of an Element in a Sorted Array of Infinite Numbers

- Source: [GeeksforGeeks](https://www.geeksforgeeks.org/find-position-element-sorted-array-infinite-numbers/)
- Platform: GeeksforGeeks

## Problem Description

Given a sorted array `arr[]` of infinite numbers. The task is to search for an element `k` in the array and return its index. If not found, return `-1`.

## Examples

### Example 1:
- **Input:** `arr[] = [3, 5, 7, 9, 10, 90, 100, 130, 140, 160, 170], k = 10`
- **Output:** `4`
- **Explanation:** `10` is at index 4 in array.

### Example 2:
- **Input:** `arr[] = [2, 5, 7, 9], k = 3`
- **Output:** `-1`
- **Explanation:** `3` is not present in array.

## Constraints

- `1 <= k <= 10^9`
- Array elements are in sorted order and infinite in length.
